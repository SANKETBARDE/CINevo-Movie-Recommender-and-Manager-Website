# 🎬 CINEvo - Movie Recommender Website & Application

CINEvo is a movie recommendation website and application designed to help movie lovers discover new films based on their preferences. Whether you’re in the mood for action, drama, comedy, or thriller, CINEvo suggests personalized movie recommendations along with detailed information about each movie.

# 🚀 Features
* Personalized movie recommendations based on genres and user preferences
* Browse popular, trending, and top-rated movies
* Detailed movie information: synopsis, cast, ratings, release date, and more
* Responsive design for seamless experience on both web and mobile
* Simple and intuitive user interface
* Lightweight and fast performance

# ⚡ Technologies Used
* Frontend: HTML, CSS, JavaScript, Bootstrap Icons
* Backend: Node.js, Supabase, Netlify Forms
* Movie Data Source: TMDb API
* Deployment: Netlify
